#  Solar System

An interactive 3D/2D Solar System simulation built with web technologies, visualizing the planets orbiting the Sun in real-time.




##  Features

-  Realistic orbital animation of all 8 planets
-  Central Sun with glowing effect
-  Planet size and distance proportionally represented
-  Smooth CSS/Canvas/Three.js animations
-  Responsive design for all screen sizes

##  Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla / Three.js)** <!-- Edit as per your stack -->
